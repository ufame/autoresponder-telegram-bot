### Комманды  
Ключи и ответы:  
`/add_key` - добавить новый `ключ`  
`/del_key` - удалить существующий `ключ`  
`/get_keys` - вывести список `ключей`  

Администраторы  
`/add_admin` - добавить нового `администратора`  
`/del_admin` - добавить нового `удалить администратора`  

### Запуск бота на своей территории :d  

`npm install -g yarn` - установка пакетного менеджера `yarn`  
`yarn install` - установка всех зависимостей  
`yarn compile` - скомпилирует `TypeScript` исходный код в исполняемый в папку `./lib`  
`yarn start` - стартовать бота  
`yarn dev` - стартовать бота с отслеживанием изменений (внесли правки в исходный код - скомпилировали - бот автоматически перезапустится)
